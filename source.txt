=======
LEGEND
=======
. = Background
T = Target_frame0
W = Wall
C = Crate
L = Ladder
Target = Target_frame0 or Target_frame1
@ = Crate and Target_frame0
p = PlayerStanding
PlayerFalling = PlayerLFalling or PlayerRFalling
PlayerR = PlayerR_frame0 or PlayerR_frame1 or PlayerR_frame2
PlayerL = PlayerL_frame0 or PlayerL_frame1 or PlayerL_frame2
Player = PlayerStanding or PlayerFalling or PlayerR or PlayerL

( Keep Core Objects below, edit or remove the examples in lowercase. )
PlayerActive = PlayerR or PlayerL

(Shorthand to check if and object has directional instructions)
Direction = GoU or GoD or GoR or GoL


(Objects that fall until they hit a Platform.)
Falling = Player or Crate

(Obstacles can't be passed from any directions e. walls, creatures, etc.)
Obstacle = Crate or Wall

(Platform is something player can walk on. Unless the Platform object is also an Obstacle they can be passed through horizontally. By default player can jump and drop through platforms.)
Platform = Obstacle or Crate or Ladder
Animation = Animated

======
RULES
======

(Target Animation)
( If Target is currently on frame 1 and hasn't animated yet this tick, flip it to frame 0 and attach the NextFrame marker to block single-turn cascades )
[stationary Player] [ Target_frame1 no Animated ] -> [stationary Player] [ Target_frame0 Animated ] 
[stationary Player] [ Target_frame0 no Animated ] -> [stationary Player] [ Target_frame1 Animated ] 

( 1. Player turning - MUST COME FIRST )
[ right PlayerStanding ] -> [ PlayerR_frame0 ]
[ left  PlayerStanding ] -> [ PlayerL_frame0 ]
[ right PlayerL ]        -> [ PlayerR_frame0 ]
[ left  PlayerR ]        -> [ PlayerL_frame0 ]

( 3. Player Animation - Runs after turning )
( If facing/moving right on frame 2 and hasn't animated yet this tick, loop back to frame 0 and attach the NextFrame marker to block single-turn cascades )
[ right PlayerR_frame2 no Animated ] -> [ right PlayerR_frame0 Animated ]
[ right PlayerR_frame1 no Animated ] -> [ right PlayerR_frame2 Animated ]
[ right PlayerR_frame0 no Animated ] -> [ right PlayerR_frame1 Animated ]
[ up PlayerR_frame2 no Animated ] -> [ up PlayerR_frame0 Animated ]
[ up PlayerR_frame1 no Animated ] -> [ up PlayerR_frame2 Animated ]
[ up PlayerR_frame0 no Animated ] -> [ up PlayerR_frame1 Animated ]
[ left PlayerL_frame2 no Animated ] -> [ left PlayerL_frame0 Animated ]
[ left PlayerL_frame1 no Animated ] -> [ left PlayerL_frame2 Animated ]
[ left PlayerL_frame0 no Animated ] -> [ left PlayerL_frame1 Animated ]
[ up PlayerL_frame2 no Animated ] -> [ up PlayerL_frame0 Animated ]
[ up PlayerL_frame1 no Animated ] -> [ up PlayerL_frame2 Animated ]
[ up PlayerL_frame0 no Animated ] -> [ up PlayerL_frame1 Animated ]
[ Animated ] -> [ ]

(On top of Platform there's a SafeZone, that pevents Falling objects from, you know, falling.)
up [ Platform | ] ->  [ Platform | SafeZone ]
up [ no Platform  | ] -> [ | no SafeZone ]


(If a Falling object is not in a SafeZone (and has no directional orders) it falls)
[ Falling no SafeZone no Direction ] -> [ down Falling ]

(Player takes a falling pose.)
[ PlayerR no SafeZone no Direction ] -> [ PlayerRFalling ]
[ PlayerL no SafeZone no Direction ] -> [ PlayerLFalling ]

(Player landing)
[ PlayerRFalling SafeZone no Direction ] -> [ PlayerR_frame0 SafeZone]
[ PlayerLFalling SafeZone no Direction ] -> [ PlayerL_frame0 SafeZone ]

(2. The diectional are iterpreted, standing frame is just turned into a walking frame, actually moving objects are told to move on...)
[ stationary PlayerR GoR ] -> [ right PlayerR GoR ]
[ stationary PlayerR GoR ] -> [ PlayerR ]
[ stationary PlayerL GoL ] -> [ left PlayerL GoL ]
[ stationary PlayerL GoL ] -> [ PlayerL ]

[ stationary PlayerLFalling GoL ] -> [ left PlayerLFalling GoL ]
[ stationary PlayerRFalling GoR ] -> [ right PlayerRFalling GoR ]

[ stationary PlayerLFalling GoD ] -> [ down PlayerLFalling GoD ]
[ stationary PlayerRFalling GoD ] -> [ down PlayerRFalling GoD ]

(Pushing Crates. Crates wont make any sense without this.)
right [ > PlayerR | Crate ] -> [ > PlayerR GoR | > Crate ]
left  [ > PlayerL | Crate ] -> [ > PlayerL GoL | > Crate ]


[ left  PlayerL no Direction ] -> [ PlayerL GoL ]
[ left  PlayerL no Direction ] -> [ PlayerL GoL ]

(Make sure trying to move up or down when it's not possible wont cause a tick)
vertical [ > Player | Obstacle ] -> cancel

[ down PlayerR no Direction ] -> [ PlayerRFalling GoD ]
[ down PlayerL no Direction ] -> [ PlayerLFalling GoD ]

[ action PlayerR no Direction ] -> [ up PlayerRFalling up GoR ] sfx0
[ action PlayerL no Direction ] -> [ up PlayerLFalling up GoL ] sfx0

(3. ...and are finally moved.)
[ right Player GoR ] -> [ right Player ]
[ left  Player GoL ] -> [ left  Player ]
[ down  Player GoD ] -> [ down Player ]
[ action    Player GoU ] -> [ up Player ]

(Clear up the go-instructions that are sometimes left lingering )
[ Direction no Player ] -> [ ]

( Player turning
[ right PlayerStanding ] -> [ PlayerR_frame0 ]
[ left  PlayerStanding ] -> [ PlayerL_frame0 ]
[ right PlayerL ] -> [ PlayerR_frame0 ]
[ left  PlayerR ] -> [ PlayerL_frame0 ])

[ > Crate | Target no Crate ] -> [ | action Crate Target ]
